3. 집계 실행 (POST /aggregations) — 팀장·ADMIN

⭐ 과거/특정 월 수동 집계 (백필). 대시보드 데이터는 여기서 먼저 만들어야 나옴   
YYYYMM 형식. 같은 달 다시 돌려도 안전(덮어씀). 자동은 매일 02시(당월+전월).

4. 대시보드 위젯 (조회) — 인증

① 월별 개발량 (GET /dev-volume) — SR 건수
unit=all(전사) | dept(부서: unitId=2139) | part(부서-파트: unitId=2139-P01) | dev(사번: unitId=7451). period=6m|12m
② 가용량/가동률 (GET /resource)
unit=all | dept(unitId=2139) | part(unitId=2139-P01). all은 unitId 불필요.
/resource/overtime : dept만 or dept+part(예 dept=2139,part=P01). part만 주면 400.
③ 주요 SR Top (GET /sr-projects)
minMm 계획공수 기준(기본 0.6). type=SR_TPCD(예 01 개발요청). 5개씩 페이징.

5. 공통코드 (codes) — 조회는 인증 / 쓰기는 팀장·ADMIN

조회 (GET /codes?grpCd=)
그룹: SR_TPCD, SR_CLS, EMP_ROLE, EMP_STATUS, DEPT_CD(부서), PART_CD(파트)
등록/수정/삭제(비활성화)

6. 인력/인사 (developers) — 조회는 인증 / 쓰기는 팀장·ADMIN

조회
